# Code of Conduct

## Our pledge

We want this to be a welcoming place for people making their very first open
source contribution. Everyone participating — maintainers, first-timers,
reviewers — is expected to help keep it that way.

## Expected behavior

- Be respectful and patient, especially with people who are new to git and
  GitHub. Everyone was a beginner once.
- Give constructive feedback on pull requests. Explain *why*, not just *what*.
- Assume good intent. A typo or a wrong format in a first PR is a learning
  moment, not a violation.

## Unacceptable behavior

- Harassment, insults, or personal attacks in issues, PRs, or comments.
- Discriminatory jokes or language.
- Publishing others' private information without consent.

## Reporting

If you experience or witness unacceptable behavior, open an issue tagged
`conduct`, or if that doesn't feel safe, contact the maintainer directly via
their GitHub profile. Reports will be handled discreetly.

## Enforcement

Maintainers may remove comments, close PRs/issues, or block participants who
violate this Code of Conduct. This project follows the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/), abbreviated here
for a small, beginner-focused repo.
