# GitHub Student Developer Pack

## What it is

The [GitHub Student Developer Pack](https://education.github.com/pack) is a
free bundle of developer tools and services for verified students. It's a
good idea to activate it before you start contributing — some of the tools
(like GitHub Copilot) make reading unfamiliar codebases a lot easier.

## Eligibility

- You need a valid school-issued email address, or documentation proving
  current student status (student ID, enrollment letter).
- Sign up at https://education.github.com/pack and follow the verification
  flow. Verification is handled by GitHub, not by this repo.
- Approval can take anywhere from a few minutes to a few days.

## Offers worth activating first

The full catalog changes over time — always check the
[official pack page](https://education.github.com/pack) for the current list.
A few that are consistently useful when you're starting out in open source:

- **GitHub Copilot** — free access while verified as a student; useful for
  understanding unfamiliar code, not a replacement for actually learning it.
- **A free custom domain** (from partners like Namecheap) — handy once you
  want a personal site or portfolio to link from your GitHub profile.
- **Cloud credits** (DigitalOcean, Azure, etc.) — useful once you're
  contributing to or building projects that need to run somewhere other than
  your laptop.
- **GitKraken / other git GUIs** — optional, but some people find a visual
  git client easier while they're still building command-line muscle memory.

## A note on scope

None of this is required to complete the practice exercise in this repo — you
only need a free GitHub account. The Student Pack is worth activating because
you're already here learning git and GitHub, not a prerequisite for anything
in `CONTRIBUTING.md`.
