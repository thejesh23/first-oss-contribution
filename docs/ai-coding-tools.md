# Helpful AI Coding Tools

None of these are required to complete the practice exercise in this repo —
you only need git and a GitHub account. But once you start reading unfamiliar
codebases and looking for a first real issue to work on, these can genuinely
help. This is a personal, opinionated shortlist, not an exhaustive catalog —
and like anything in this space, it'll go stale, so treat it as a starting
point rather than the final word.

## Superpowers

[github.com/obra/superpowers](https://github.com/obra/superpowers)

A skills framework for Claude Code that gives the agent a disciplined
development methodology — brainstorming a design before writing code, writing
plans before implementing, using TDD, requesting code review, and more. If
you're using Claude Code to help with your contribution, this changes it from
"writes code fast" to "follows a process," which matters a lot once you're
working in someone else's codebase under someone else's review standards.

## Understand Anything

[github.com/Egonex-AI/Understand-Anything](https://github.com/Egonex-AI/Understand-Anything)

A Claude Code plugin that analyzes a codebase and builds an interactive
knowledge graph of its files, functions, classes, and dependencies, so you
can explore and ask questions about it visually instead of reading blind.
Useful exactly at the moment described in
[docs/finding-your-first-issue.md](finding-your-first-issue.md): you've found
a promising repo and an issue, and now you need to figure out how the
codebase actually fits together before you touch anything.

## Continue

[continue.dev](https://continue.dev)

An open-source AI coding assistant that runs as an extension in VS Code and
JetBrains IDEs, so you get inline suggestions and chat without leaving your
editor. A lighter-weight option if you'd rather stay in your IDE than use a
terminal-based tool.
